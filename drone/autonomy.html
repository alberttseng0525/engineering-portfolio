The current software stack combines MAVSDK flight control, live target offsets, telemetry, mission-state logic, and a MAVLink-controlled payload interface.

Raspberry Pi ↔ Pixhawk communication

I established communication between the companion computer and PX4 through MAVLink. The Raspberry Pi sends higher-level commands and receives telemetry while PX4 handles low-level stabilization and state estimation.

Mission logic

Autonomous state machine

The flight-control program uses explicit states so each part of the mission can be tested and transitioned independently.

TAKEOFFarm + climb
GRID SEARCHsearch pattern
ALIGNcenter target
DESCENDcorrect + descend
GRABpayload command
ASCENDclimb
RTLreturn home
Visual alignment

Image error to velocity command

The detector returns normalized dx and dy target errors. The controller converts those values into bounded North/East velocity commands. During descent, the system continues to correct horizontal alignment and can return to the ALIGN state if the error becomes too large.

# simplified control concept
dx, dy = detector.get_offset(frame)
velocity_north = clamp(k * dy)
velocity_east  = clamp(k * dx)

if aligned:
    state = DESCEND
