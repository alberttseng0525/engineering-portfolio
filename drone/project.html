Overview

Project objective and system architecture

The goal is to build a drone that can detect a target package, navigate toward it, retrieve it with a custom mechanism, and return autonomously.

Mission

Target workflow

The autonomous mission is divided into five stages.

01Search

Fly a predefined search pattern while processing the onboard camera feed.

02Detect

Identify the target and calculate its location relative to the center of the image.

03Align

Convert visual error into horizontal flight corrections.

04Retrieve

Descend while maintaining alignment and actuate the pickup mechanism.

05

Return

Ascend with the payload and return to the launch point.

Architecture

Hardware and software stack

The Raspberry Pi handles perception and mission logic. PX4 on the Pixhawk handles state estimation and low-level flight control.
