Inside the FRC work ↗
  1. Jan–Mar 2025

    FRC Game-Piece Object Detection ↗

    Collecting images, labeling game pieces, and testing a detector beyond its validation scores.

    Computer vision · Limelight
  2. May–Dec 2025

    LabVIEW-to-Java Robot Migration ↗

    Contributing to a team migration from LabVIEW to Java, integrating subsystems and debugging command conflicts.

    Java · Robot integration
  3. Oct 2025–Mar 2026

    Multi-Camera AprilTag Localization ↗

    Combining camera observations and odometry into a shared estimate of robot pose.

    AprilTags · Sensor fusion
  4. Jan–Sep 2026

    Shoot-on-the-Move Aiming System ↗

    Connecting measured shots, simulated trajectories, and chassis velocity to aiming setpoints.

    Ballistics · Real-time control
  5. 2026–Present

    PX4 Delivery Drone Development ↗

    Building and tuning a PX4 drone, with onboard vision and autonomy under development.

    PX4 · CAD · Onboard vision
